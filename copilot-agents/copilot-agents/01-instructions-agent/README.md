# Instructions Agent - Guide

## O que faz?

Cria arquivo de **INSTRUCTIONS** globais para seu projeto (~55 linhas)

## Arquivos nesta pasta

- `agente-instructions.md` - O agente completo com fluxo passo-a-passo
- `TEMPLATE-instructions.md` - Template vazio para você preencher

## Como usar?

1. Abra `agente-instructions.md`
2. O agente fará ~5 perguntas sobre seu tech stack
3. Ele gera um template com as 6 seções obrigatórias
4. Ele valida automaticamente
5. Copie o resultado para `.github/copilot-instructions.md`

## Seções que serão criadas

1. Tech Stack Overview
2. Naming Conventions
3. Project Structure
4. Error Handling Pattern
5. TypeScript Requirements
6. Testing Standards

## Tempo estimado

5-10 minutos para responder às perguntas + geração automática

## Token cost

40-80 tokens por requisição (SEMPRE carregado)
