# Agents Agent - Guide

## O que faz?

Cria **AGENTS** especializados para seu projeto (@developer, @pm, @tech-lead, etc)

Cada agente é uma persona com responsabilidades, estilo de comunicação e tools específicas.

## Arquivos nesta pasta

- `agente-agents.md` - O agente completo com fluxo passo-a-passo
- `TEMPLATE-agent.md` - Template vazio para você preencher
- `exemplos/` - Exemplos prontos
  - `exemplo-developer.agent.md` - Agent de desenvolvimento

## Como usar?

1. Abra `agente-agents.md`
2. Descreva a persona (nome, foco, tools, modelo)
3. Ele gera template com YAML frontmatter
4. Ele valida estrutura e seções
5. Copie para `.github/agents/seu-agente.agent.md`
6. Use via `@seu-agente` no Copilot

## Seções que serão criadas

1. Core Responsibilities
2. Communication Style
3. Decision-Making Framework
4. Tools & Integrations
5. Handoff Triggers

## Exemplos

Veja `exemplo-developer.agent.md` para referência:
- Mostra estrutura com YAML completa
- Tem todas as seções obrigatórias
- Tem tools e handoffs definidos

## Tempo estimado

5-10 minutos por agente

## Token cost

~50 tokens quando selecionado (@developer, etc)
